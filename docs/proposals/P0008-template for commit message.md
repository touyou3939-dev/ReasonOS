## Purpose

Introduce a standard Commit Message template to support consistent commit messages across the ReasonOS repository.

---

## Proposed Change

Create `docs/templates/Commit Message.md`.

The template contains:

### Summary

```
<type>: <short description>
```

Example:

```
docs: define Open Question index
```

### Description

```
- change 1
- change 2
- change 3
```

The template is intended to be used consistently regardless of the Git client.

---

## Rationale

A shared template reduces ambiguity when writing commit messages and complements the Commit Proposal workflow by keeping commit formatting consistent across the repository.
