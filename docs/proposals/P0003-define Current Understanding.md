## Purpose

Define the role and responsibilities of **Current Understanding** as a core concept of ReasonOS.

---

## Proposed Change

Update `docs/Current Understanding.md` with the following structure.

### Purpose

- Current Understanding defines the current agreed understanding of ReasonOS.
- It serves as the authoritative reference for the current understanding of the system.
- Only reviewed and accepted knowledge belongs in this document.

### Responsibilities

Current Understanding is responsible for:

1. Recording the current agreed understanding.
2. Defining the concepts currently accepted by ReasonOS.
3. Defining the principles currently accepted by ReasonOS.
4. Providing a stable reference for future design decisions.

### Non-Responsibilities

Current Understanding does not contain:

- Open Questions
- Draft ideas
- Design discussions
- Historical records
- Experimental concepts

These belong in their respective documents.

### Update Policy

Current Understanding is updated only after a Commit Proposal has been reviewed and accepted.

Each update replaces the previous understanding with the newly accepted understanding while preserving the design history in the repository.

---

## Rationale

Use **"authoritative reference"** instead of **"truth"** because ReasonOS preserves the current agreed understanding rather than objective truth.

Current Understanding is not only a record of accepted understanding but also a stable baseline for future design decisions.
